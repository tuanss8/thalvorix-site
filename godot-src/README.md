# THALVORIX Duel Arena 3D — Godot prototype

Godot 4.7.2-stable, GDScript only, Compatibility renderer (WebGL2). Published build: https://thalvorix.xyz/duel-arena/ (moved from /godot/ 2026-11-09 per Yazz — /godot/ now redirects there; the 2D duel game still lives at /duel-arena.html).

- `main.gd` – scene, UI, rules, bot, animations (everything is built in code)
- `card.gd` – 3D card (art, name, ATK/DEF, back, glow)
- `hero_data.gd` – all 100 heroes (id = on-chain `heroIdOf`, art `hd/h<id>.webp` resized to 256 px JPG in `heroes/`) + the 20-hero default pool
- `shell.html` – custom web shell: deck chooser (connect wallet / paste address / random) + bot difficulty from the player's rank (reads `thx_rank_<wallet>` from localStorage → `window.THX_TIER`), read-only NFT scan via public BSC RPC + Multicall3, on-screen error box, WebGL-context-lost notice and a 60 s start watchdog. Passes the deck to Godot as `window.THX_DECK`.
- `audio/` – SFX wav (22050 Hz mono) + recorded voice callouts (mp3, the same clips as the 2D duel game in `/vo`). The 56 s war-loop `music.ogg` was REMOVED 2026-11-09 per Yazz — no background music; the file is deleted from the repo (still in git history if ever wanted back). SFX: `deal` (card fly-in), `flip` (card flip), `select` (card picked), `hit` + `clash` (attack impact: low thud + metallic sword ring), `shatter` (card destroyed), `lp` (LP damage, pitch-drop thud), `turn` (player turn chime), `fanfare` (duel-start trumpet), `win`/`lose`. Voice lines (added 2026-11-09 per Yazz — the formant-synthesized barks added that morning were REMOVED the same day; these are the REAL recorded clips from the 2D game): `duel_started`, `your_turn`/`enemy_turn` (1st turn + every 4th), `attack1-3` (random per attack), `destroy1-2` (per shatter), `summon1-3` (per refill after the first deal), `victory`/`defeat`, `warn_en` (your LP ≤ 250, once) / `win_en` (enemy LP ≤ 250, once). One voice player: a new line stops the old one, throttled to one line per 600 ms (like the 2D game's `vplay()`). Mute via the "Sound: ON/OFF" button (mutes SFX + voice). New SFX (2026-11-09, `clash`/`turn`/`lp`/`fanfare`) are synthesized with numpy — see `~/workspace/godot/make_duel_sfx.py`.
- Bot difficulty (2026-11-09, mirrors the 2D game's `duelBotDiff`): Easy = bot ATK ×0.6 / DEF ×0.8 and 50% random moves; Normal = ×0.85 / ×0.9 and 25% random (the original behaviour); Hard = ×1.0 / ×1.0 and always the best move. Difficulty follows the player's rank tier, read from the 2D game's `thx_rank_<wallet>` record in localStorage: Easy for tiers 0–2 (Ashen Recruit–Bronze Warden), Normal for 3–5 (Silver Sentinel–Sapphire Knight), Hard for 6–7 (Diamond Warlord–Mythic Thalvorian); no record (new player) = tier 0 = Easy. No manual picker — the chooser shows the rank and the bot level after the wallet is connected.

Rules: 5 slots per side, 8-card deck each, LP 4000. Pick your card, then an enemy card.
ATK > target DEF → target destroyed, owner loses the difference. ATK < DEF → attacker's owner loses the difference.
Equal → both destroyed. Empty slots refill from the deck at each turn. Win at enemy LP 0 or when the enemy has no cards.

Export (single-threaded web, no COOP/COEP needed), then generate the service worker:

    godot --headless --path godot-src --export-release "Web" duel-arena/index.html
    python3 godot-src/tools/post_export.py duel-arena

`post_export.py` writes `duel-arena/sw.js` (cache name = hash of the exported files). Always run it after an export, or repeat visitors keep the previous cached build until it runs.

Engine sharing (2026-11-09): `duel-arena/` holds only the game data (`index.pck`), the shell (`index.html`, `index.js`) and the icons — the engine (`index.wasm` 39.5 MB + audio worklets) is shared from `/godot/`, because the GitHub web UI refuses files over 25 MB and the wasm cannot be re-uploaded there. The wasm is byte-identical across exports from the same Godot version, so sharing it is safe. `shell.html` points the loader there (`GODOT_CONFIG.executable = '/godot/index'`, wasm preloaded from `/godot/index.wasm`), and `post_export.py` leaves the engine files out of the `duel-arena/` service-worker cache (they load from `/godot/` via the HTTP cache instead). NEVER delete the `godot/` folder or its engine files — `/duel-arena/` stops working without them. The upload set for `duel-arena/` is 7 files: `index.html`, `index.js`, `index.pck`, `sw.js`, `index.png`, `index.icon.png`, `index.apple-touch-icon.png` (no wasm, no worklets).

Loading pipeline (2026-11-09):
- `<link rel="preload">` for index.wasm/index.pck in the shell head starts both downloads before index.js runs (same URL + cors mode as the Godot loader: one fetch each, verified).
- The shell starts downloading `index.wasm` + `index.pck` and compiles/instantiates the engine (`engine.init`) as soon as the page opens, while the player picks a deck; Play only calls `engine.start`. Progress shows `Downloading game… N%` (both files), then `Preparing engine…` (compile), `Starting engine…`, `Building the arena…`. The overlay stays until Godot calls `window.THX_onTitle()` after the title frame (20 s fallback).
- `sw.js` (registered 3 s after the title shows, scope `/duel-arena/`) precaches this build from the HTTP cache and serves it cache-first on repeat visits; a new export = new cache name, old caches are deleted on activate. `?nosw` skips registration. The old `/godot/` folder keeps only a redirect stub (`index.html` → `/duel-arena/`) and a stub `sw.js` that clears old caches and unregisters itself.
- Startup order in `main.gd`: lights/camera → table + UI → title frame → backdrop over the following frames → one hidden card drawn under the table to pre-compile card shaders. Backdrop textures are baked PNGs in `space/` (regenerate with `godot --headless --path godot-src -s res://tools/bake_space.gd`); the generator functions stay in `main.gd`. The 4 planet rim shells share one Shader (one GPU program).
- Timing marks: `window.THX_T` (GDScript side, performance.now ms) and `window.THX_STAGES` (shell side).

Debug: `godot --path godot-src -- --autoplay --shots` plays a bot-vs-bot game and saves screenshots to user://.

Wallet deck: `window.THX_DECK = {wallet, heroes:[{token, hero, rar}]}` is read in `main.gd` via `JavaScriptBridge`. Your NFTs are drawn first; wallets with fewer than 8 are padded with random heroes. No signing, no transactions.

Note: keep `glow_enabled = false`. The Compatibility-renderer glow pass crashed the browser GPU process (WebGL context lost) during the first frame, which left the loading screen stuck.

Camera orbit (2026-11-09): one-finger horizontal drag (or mouse drag) orbits the camera around the table (yaw, clamped ±70°, eased); Left/Right arrow keys step 12°. A press only counts as a tap if it moves less than 18 px. Two-finger drag pans (a little at normal zoom, more when zoomed in); pinch still zooms (zoom = orbit distance). Reset returns to the front view. The far starfield/nebula layers follow the camera, planets stay put, so the backdrop parallax follows the orbit. `window.THX_CAM` now also has `orbit`/`orbitT` (degrees).

Camera pitch / zoom (2026-11-09): mouse wheel scrolls the camera UP/DOWN (pitch/elevation 15°–80°, default ~54° — scroll up for a top-down view of the board, scroll down for a low front view); the ▲/▼ buttons on the right edge do the same on touch. Zoom is now pinch + the +/− buttons only (wheel no longer zooms). Zoom is a camera-distance multiplier clamped to 0.6–2.2, smoothed in `_process`; screen shake is applied on top of the zoomed transform. When zoomed in, a one-finger drag pans (clamped to the board); card taps now fire on release and are cancelled only by a pan drag or a multi-finger gesture. The shell blocks browser page zoom (viewport meta, `touch-action:none`, gesture/ctrl+wheel/multi-touch `preventDefault`). On the web, `window.THX_CAM` (now also `pitch`, degrees) and `window.THX_STATUS` expose zoom/pan/pitch and the status line for automated tests.

Auto-enter + rank + Next + Settings (2026-11-09): if the wallet is already connected on thalvorix.xyz (`thx_session` in localStorage), the chooser is skipped and the wallet's deck loads straight away (Quit in-game returns to the chooser once via a session flag). Rank progression mirrors the 2D game exactly (`onEnd`: win +1 star, loss −1 star, 25 stars/division, division I promotes to the next tier's X, Ashen Recruit never loses stars, Mythic top earns Glory points) and is saved to the same `thx_rank_<wallet>` localStorage record (plus a best-effort Supabase `save-rank` push reusing the 2D game's cached `thx_rsig_<wallet>` signature), so rank carries across the 2D and 3D games. On victory the result button reads "Next" (starts a fresh match vs a new bot deck; PvP matchmaking is still a later phase). The Settings button (top-right) opens a panel with a volume slider (shared `thx_vol` with the site, 0–100, drives the master bus), Pause (soft-pauses the turn flow; Resume continues) and Quit to menu. Mute ("Sound: ON/OFF") is separate from volume.

3D backdrop (`_build_space`, built over several frames): 3 parallax starfield layers (billboard MultiMesh quads, twinkle shader; far layers follow the camera, the near one stays put), additive nebula billboards with a 96 px procedural cloud texture, 4 REAL planets (Jupiter, ringed Saturn with a real ring profile, Earth, Neptune) from Solar System Scope / NASA 2k maps downscaled to 1024×512 PNGs in `space/` (built by `~/workspace/godot/make_planet_textures.py`; 1024x512 since 2026-11-09 — 512x256 looked pixelated on the big planets; the old procedural `_planet_tex` generator is no longer used for planets — do NOT re-bake them) on smooth spheres (64 radial segments / 32 rings for large planets, 48/24 for small — raised from 28/14 the same day, the faceted silhouette also looked broken) plus fresnel atmosphere shells (also 64/32 — the shell's 24-segment edge was the visible polygon on the planet circles, fixed 2026-11-09) and Saturn's ring at 128 segments, a cratered Moon in orbit around Jupiter, a distant Sun with a real fiery surface texture + corona, and a small asteroid belt. Low-poly spheres, no shadows, glow still off.

Board slots + card back (2026-11-09): the 10 slot plates are (nearly) clear — one shared `SLOT_SHADER` in `main.gd` (unshaded, blend_mix, `depth_draw_never`, fill alpha ~0.02, only a thin bright rim + corner accents) so the galaxy shows through the board; the table itself is dark glass (alpha 0.32) for the same reason, with the gold rim + mid line still anchoring it. The gold rim is a 4-bar FRAME (open middle), not a solid slab — the slab's gold top face shone through the glass table and turned the whole board gold (fixed 2026-11-09); the frame was thinned to 0.08 bars + dimmer emission 0.4 the same day per Yazz so it doesn't stand out. Card backs (deck/hand/board and the deck-pile tops) use one shared material with the baked `cardback.png` (352×512, 192-colour PNG, imported lossy WebP), regenerated with `python3 godot-src/tools/make_cardback.py`. Glow stays off.

Card text (2026-11-09): name/role/ATK/DEF are Label3D with auto-fit in `card.gd` (`_flat_label` measures the string with the fallback font and scales `pixel_size` so text never wraps or overflows the card) — name 44, role 28, ATK/DEF 28, outline 10, brighter colours (sized down from 52/32/32 the same day per Yazz: not too big, not too small, neat and readable). Glyphs render at 2x font size with halved `pixel_size` (same world size, much sharper letters — the low-res glyphs looked pixelated), no hard alpha cut (smooth blending instead of the jagged discard threshold), anisotropic texture filtering. ATK/DEF sit on a solid dark stat strip at the bottom of the card (like the 2D duel cards) with the original colours (ATK orange, DEF blue — the near-white version was reverted the same day per Yazz) and max width 0.50 at ±0.25 — shrunk from 32 / 0.58 / ±0.26 on 2026-11-09 per Yazz because the outline around 3-digit stats could still poke past the card edge. LP HUD (`lp_hud.gd`): `_rrect` skips rects narrower than 4 px and drops duplicate arc-junction vertices — a hair-thin bar used to triangulate into a degenerate polygon ("Invalid polygon data, triangulation failed" red banner in the web build when LP drained to 0; fixed 2026-11-09).
